# 📚 독서 기록

독서를 기록하고, 얼마나 읽었는지 통계로 보고, 목표를 세워 진척도를 추적하는 로컬 웹앱.
데이터는 전부 이 폴더 안에만 저장된다. 어디에도 올라가지 않는다.

---

## 시작하기

`run.bat` 을 더블클릭한다. 끝.

처음 한 번은 파이썬 가상환경을 만들고 라이브러리를 받느라 1~2분 걸린다.
그 다음부터는 바로 뜨고, 브라우저가 자동으로 열린다.

- 이 PC: <http://127.0.0.1:8765>
- 끄는 법: 검은 창에서 `Ctrl+C`

파이썬 3.10 이상이 필요하다. 없으면 [python.org](https://www.python.org/downloads/) 에서
설치할 때 **"Add Python to PATH"** 를 꼭 체크한다.

## 쓰는 법

### 책 추가

오른쪽 위 **+ 책 추가**. 알라딘 TTB키를 등록해 뒀다면 제목으로 검색해서 담으면
저자·출판사·표지·총 페이지가 자동으로 채워진다. 키가 없으면 직접 입력 폼이 바로 뜬다.

상태는 네 가지다.

| 상태 | 뜻 |
|---|---|
| 읽고싶은 | 위시리스트. 진도를 한 번 기록하면 자동으로 "읽는 중"이 된다 |
| 읽는 중 | 진행 중 |
| 완독 | 다 읽음. 별점과 한줄평을 남긴다 |
| 중단 | 덮어둔 책 |

### 진도 기록 — 이게 전부다

**따로 "오늘 독서 입력" 화면이 없다.** 대시보드의 책 카드에서 현재 페이지만
바꾸고 `기록`을 누르면 된다.

```
사피엔스   [ 455 ] 쪽까지  [기록]
   ↓
2026-07-30 / 사피엔스 / +43p   ← 자동으로 쌓인다
```

이 한 줄이 하루 평균 페이지, 연속 독서일, 월별 그래프, 잔디의 재료가 된다.

- **같은 날 여러 번 눌러도 그날 기록은 한 줄로 합쳐진다.** 아침에 430, 밤에 470을
  넣으면 `+58p` 한 줄이 된다.
- 잘못 눌렀으면 원래 숫자로 되돌리면 된다. 그날 기록이 같이 줄어든다.
- 시간(분)은 책 상세 화면에서 선택 입력. **하루 시간 목표를 쓰려면 이걸 같이 넣어야
  집계된다.**
- 마지막 쪽에 닿으면 완독할지 물어본다. 자동으로 끝내지 않는다.
- 예전에 읽은 책은 진도 없이 완독으로만 등록해도 된다. 대신 그 책은 일일 통계에
  잡히지 않는다.

### 목표

**설정** 화면에서 세 가지를 정한다. 비워 두면 그 목표는 꺼진다.

| 목표 | 예 | 보여주는 것 |
|---|---|---|
| 연간 권수 | 24권 | 진행률 링, "이 페이스면 연말 21권", 계획선 대비 앞섰는지 |
| 하루 페이지 | 30p | 오늘 달성 바, 연속 기록(streak) |
| 하루 시간 | 30분 | 오늘 달성 바 |

**책별 마감일**은 설정이 아니라 각 책의 상세 화면에서 정한다. 넣으면
`남은 21일 / 하루 11p 필요`, 그리고 최근 2주 실제 속도로 계산한
`지금 속도면 8/18 완독 예상` 이 같이 나온다. 마감을 넘길 것 같으면 빨갛게 표시된다.

연속 기록은 하루 목표를 정했으면 **목표를 채운 날**, 안 정했으면 **읽은 날** 기준이다.
오늘이 아직 안 끝났으므로 오늘 안 읽었다고 연속이 끊긴 것으로 치지 않는다.

### 통계

연도를 골라서 본다. 월별 페이지/권수, 1년치 잔디 달력, 최근 90일, 카테고리,
별점 분포, 저자·출판사 순위, 평균 완독 소요일.

## 알라딘 TTB키 (선택)

없어도 앱은 그대로 다 쓴다. 등록하면 책 추가가 훨씬 편해진다.

1. 알라딘에 회원가입 후 로그인
2. **고객센터 → 상품 정보 API (OpenAPI)** 에서 사용 신청
3. 발급된 키를 앱의 **설정** 화면에 붙여넣고 저장

키는 `data/config.json` 에만 저장된다. 독서 기록 DB나 CSV 내보내기에는 들어가지
않으므로, 기록을 남에게 보내도 키가 딸려 나가지 않는다.

> 알라딘에 **페이지 수가 등록돼 있지 않은 책이 꽤 있다.** 그런 책은 담을 때
> "페이지 수 없음 — 직접 입력" 이라고 뜬다. 책 뒤쪽을 보고 넣으면 된다.
> 총 페이지가 없어도 기록은 되지만 진도율과 마감 계산은 나오지 않는다.

## 폰에서 보기

`run.bat` 은 이미 같은 와이파이에서 접속할 수 있게 열어 둔다.

1. PC에서 명령 프롬프트를 열고 `ipconfig` → `IPv4 주소` 확인 (예: `192.168.0.12`)
2. 폰 브라우저에서 `http://192.168.0.12:8765`
3. Windows 방화벽이 물어보면 **개인 네트워크**에 허용

> **로그인 절차가 없다.** 같은 네트워크에 있는 사람은 누구나 열 수 있다.
> 집 와이파이에서만 쓰고, 카페·회사·공용 와이파이에서는 켜지 말 것.
> PC에서만 쓰려면 `run.bat` 의 `--host 0.0.0.0` 을 `--host 127.0.0.1` 로 바꾼다.

## 백업과 내보내기

- **백업**: 설정 → `지금 백업`. `data/backups/reading-날짜.db` 가 만들어진다.
  복원은 그 파일을 `data/reading.db` 로 덮어쓰고 앱을 다시 켜면 된다.
  (앱이 꺼진 상태에서 `data/reading.db` 를 그냥 복사해도 된다)
- **CSV**: 설정 → 책 목록 / 날짜별 기록. 엑셀에서 한글이 안 깨지게 저장된다.

## 폴더 구조

```
run.bat              실행
requirements.txt
data/
  reading.db         모든 기록 — 이 파일 하나가 전부다
  config.json        알라딘 TTB키
  backups/           백업본
app/
  main.py            앱 진입점
  db.py              스키마
  aladin.py          알라딘 클라이언트
  services/          진도·목표·통계 계산
  routers/           화면(pages) + JSON API
  templates/         화면
  static/            app.css, app.js, charts.js
scripts/
  seed.py            샘플 데이터 생성기
```

차트는 외부 라이브러리 없이 직접 그린 인라인 SVG다. CDN을 전혀 쓰지 않으므로
인터넷이 끊겨도 화면이 그대로 뜬다.

## 개발용

```powershell
# 직접 실행 (코드 고치면 자동 재시작)
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8765

# 샘플 데이터 (경계 케이스 포함 20권 / 116건)
.\.venv\Scripts\python.exe scripts\seed.py --reset

# API 문서
# http://127.0.0.1:8765/api/docs
```

주요 API:

| 메서드 | 경로 | 하는 일 |
|---|---|---|
| `PATCH` | `/api/books/{id}/progress` | 진도 갱신 → 세션 자동 생성/병합 |
| `POST` | `/api/books/{id}/finish` | 완독 처리 + 별점 |
| `PATCH` `DELETE` | `/api/sessions/{id}` | 날짜별 기록 수정·삭제 (현재 페이지 재계산) |
| `PUT` `DELETE` | `/api/goals` | 목표 저장·삭제 |
| `GET` | `/api/stats/summary` `/api/stats/charts` | 통계 |

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| `run.bat` 이 바로 닫힌다 | 파이썬 미설치. python.org 에서 설치 시 "Add Python to PATH" 체크 |
| 포트 8765가 이미 쓰인다 | `run.bat` 과 설정 안내의 포트 번호를 8766 등으로 바꾼다 |
| 폰에서 안 열린다 | 같은 와이파이인지 확인 → 방화벽에서 파이썬을 개인 네트워크에 허용 |
| 검색이 안 된다 | TTB키 확인. 그래도 안 되면 직접 입력으로 계속 쓸 수 있다 |
| 기록이 이상해졌다 | 책 상세의 "날짜별 기록"에서 직접 고치거나 지운다 |
